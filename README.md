# My AI Platform

منصة Streamlit للذكاء الاصطناعي:
- 💬 Gemini Chat
- 📎 تحليل الملفات
- 🖼️ توليد الصور
- 🎙️ تحليل الصوت
- 🎬 تحليل الفيديو

## التشغيل
```bash
pip install -r requirements.txt
streamlit run app.py
```

## النشر
اربط المستودع بخدمة تدعم Streamlit/Python، واختر الفرع `main` والملف `app.py`.

لا تضع Gemini API Key داخل الكود أو GitHub. استخدم Secrets باسم:
```
GEMINI_API_KEY
```
